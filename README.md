## 🚀 Getting Started

### Prerequisites

- **Python 3.10+** installed
- **pip** package manager

### 1. Clone / Navigate to the Project

```bash
cd "learning nlp for ml"
```

### 2. Install Dependencies

```bash
pip install flask scikit-learn nltk pandas numpy matplotlib seaborn
```

### 3. Download NLTK Data (one-time setup)

```python
import nltk
nltk.download('punkt')
nltk.download('punkt_tab')
nltk.download('stopwords')
```

### 4. Train the Model

```bash
python main.py
```

This will:
- Load and preprocess the dataset (`train.txt`)
- Train Naive Bayes models with both BoW and TF-IDF
- Print accuracy scores
- Save `model.pkl`, `vectorizer.pkl`, and `metadata.pkl`

**Expected output:**
```
198
0.7678125
0.6609375
Saved model.pkl, vectorizer.pkl, and metadata.pkl successfully.
```

### 5. Launch the Web App

```bash
python app.py
```

Open **http://127.0.0.1:5000** in your browser 🎉

## 🔌 API Reference

### `POST /predict`

Classify the emotion of a given text.

**Request:**
```json
{
  "text": "I am so happy today, feeling amazing!"
}
```

**Response:**
```json
{
  "emotion": "joy",
  "confidence": 0.9437,
```

## 🧪 Model Performance

| Vectorizer | Algorithm | Accuracy |
|:----------:|:---------:|:--------:|
| **Bag of Words** (CountVectorizer) | Multinomial Naive Bayes | **76.8%** ✅ |
| TF-IDF (TfidfVectorizer) | Multinomial Naive Bayes | 66.1% |

> **Note:** BoW outperforms TF-IDF on this dataset likely because emotion-bearing words benefit more from raw frequency counts than from TF-IDF's frequency dampening, especially in short texts.

## 🔧 Text Preprocessing Pipeline

Every input text goes through the same 5-step cleaning pipeline used during training:

```
"I can't believe it's 2026!! 😱🔥 This is AMAZING!!!"
        │
        ▼  1. Lowercase
"i can't believe it's 2026!! 😱🔥 this is amazing!!!"
        │
        ▼  2. Remove Punctuation
"i cant believe its 2026  😱🔥 this is amazing"
        │
        ▼  3. Remove Numbers
"i cant believe its   😱🔥 this is amazing"
        │
        ▼  4. Remove Emojis (non-ASCII)
"i cant believe its   this is amazing"
        │
        ▼  5. Remove Stopwords
"cant believe amazing"
```
